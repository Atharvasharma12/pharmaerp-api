# Finance Module Architecture Notes

## Objective

The Finance Module is the accounting engine of the ERP.

Every financial transaction generated by:

- Customers
- Suppliers
- Purchases
- Sales
- Receipts
- Payments
- Treasury
- GST
- Inventory Adjustments

must ultimately be recorded in Finance.

Finance becomes the single source of truth for:

```txt
Assets
Liabilities
Income
Expenses
Equity
Profit
Loss
Outstanding
Financial Statements
```

---

# Core Accounting Philosophy

Every transaction must follow:

```txt
Double Entry Accounting
```

Rule:

```txt
Total Debit
=
Total Credit
```

Example:

```txt
Customer Sale ₹10,000

Customer A/c Dr     10,000
      To Sales A/c  10,000
```

# Account Balances

Purpose:

Fast balance lookup.

---

# Why Needed

Suppose:

```txt
5000 Customers

10,00,000 Ledger Entries
```

Customer List:

```txt
Customer Name
Balance
Credit Limit
```

Calculating balance from Ledger every request becomes expensive.

---

# Solution

Maintain summary records.

---

## accountBalance.model.js

```js
{
  (accountId, debitTotal, creditTotal, balance, balanceType, lastTransactionAt);
}
```

---

# Important Rule

These are cumulative values.

```txt
debitTotal
only increases

creditTotal
only increases
```

---

Example:

```txt
Sale Dr 10000

debitTotal = 10000
creditTotal = 0
```

---

Customer pays:

```txt
Receipt Cr 4000
```

Now:

```txt
debitTotal = 10000
creditTotal = 4000
balance = 6000 DR
```

---

Formula

```txt
balance = debitTotal - creditTotal
```
